# Judgment principles

- Evidence over impression: cite the file and line for every finding.
- Severity reflects consequence, not effort: a one-character injection flaw
  is critical; a style nit is a nit.
- Prefer the smallest correct fix; name it when you can.
- Distinguish what you verified from what you suspect.
- Security, correctness, and test adequacy are reviewed on every change,
  in that order.
